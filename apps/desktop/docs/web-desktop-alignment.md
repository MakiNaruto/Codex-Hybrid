## 共用管理页面（2026-11-01）

Tauri 的 `frontendDist` 已直接指向 `src/management/web/`，桌面与浏览器共用 HTML、样式、模型管理、接入确认及诊断页面。旧 `apps/desktop/stage0/web/` 历史探针页面已清理，后续界面开发统一使用共用管理页。

浏览器保留原有鉴权 HTTP 接口；桌面经 `transport.js` → `desktop_manage` → 常驻控制进程的 `web_api` 白名单，复用 Management 业务，不启动管理 HTTP 监听。私有接口覆盖状态、活动、进程、诊断周期、来源、模型、厂商、发布、测试、接入及桌面偏好。接入仍绑定同会话预览；首次启动要求用户明确初始化，不自动开启接入或恢复转发。Key 不回显，不通过命令行传递；断连不重试写入。

`desktop.js` 只负责初始化、托盘事件与桌面生命周期。Windows 与 macOS 均支持关闭隐藏和带活动确认的独立重启。仍有网关依赖时，Windows 经确认即可退出，macOS 沿用退出前恢复预览；托盘菜单与确认业务共用，原生弹窗、进程控制和代理选择分别使用各平台实现。未保存草稿、打开的弹窗或进行中的写入会阻止托盘操作。

已在临时 HOME 的 Intel 原生窗口验证：显式初始化、三个页面导航、诊断读取、接入预览与取消、厂商保存后模型显示、草稿时 Cmd+Q 保留窗口，以及无接入时安全退出。未发送厂商连接测试，未对真实 Codex 执行退出或重启。验证以源码回归、macOS Intel 编译、临时 HOME 下的冻结程序和窗口检查为依据；不代表 Windows、Apple Silicon 或真实 Codex 启停验收。私有 stdio 仍逐条串行处理，长操作期间状态请求需等待当前操作完成。

## 会话索引属于切换业务的一部分

先前桌面方案只写路由配置事务，需同时纳入现有索引规则：

- 只处理所选 Codex 数据目录的本机会话索引，包括归档和子会话；不改 `.jsonl` / `.jsonl.zst` 历史、历史模型或分页缓存。
- 开启将索引线路改为 `codex-hybrid`，保留模型；关闭改为 `openai`，官方模型保留，第三方模型替换为目录中首个可用官方模型。官方身份按 `official_models` 判断，未设置的模型仍不设置；再次开启不自动恢复被替换的第三方模型。
- 接入配置不选择或覆盖根级 `model`，不存在可指定的迁移默认模型。缺少官方名单或必要回退模型时停止。
- 预览不启动辅助进程。确认后仅在缺少索引时调用独立 Codex app-server 的 `thread/read` 补齐元数据；不 resume、不生成，使用临时认证存储并阻止 HTTP 联网。这与观察桌面真实任务状态是两种能力，不能相互替代。
- 网页对结构不兼容、路径不安全、会话 ID 冲突或无法识别无索引元数据等指定错误，警告后跳过全部索引迁移，仍应用配置；不做部分迁移。CLI 保持严格。官方模型校验、索引补齐、预览校验、备份及实际写入错误不降级。
- 配置、恢复元数据和索引构成可恢复事务；`session-migrations/<ID>/` 为单次迁移临时记录，成功、完整回滚或恢复完成后清理，清理失败在启动和下次切换时重试。中断或回滚未完成的记录保留并阻止后续切换；首次固定基线另存于 `session-baselines/`，不覆盖、不自动清理。恢复仍须退出 Codex，通过现有 CLI 操作，不计划提供网页迁移恢复向导。
- 索引补齐可能先更新 Codex 元数据库；后续失败不删除已经补齐的索引。迁移警告显示在预览和结果，并在确认应用时尝试写入轮转警告日志；取消不写日志。

证据：`src/codex_integration/session_migration.py`、`src/codex_integration/codex_index.py`。完整操作和恢复边界见[会话迁移](../../../docs/zh-CN/session-migration.md)。

## 网页网关故障恢复（2026-10-28）

- 管理进程与网关子进程隔离；管理进程监督自己创建的子进程，通过私有进程管道接收就绪与日志事件，共享仅内存的活动计数。转发监听不提供管理接口。
- 仅网关进程意外退出触发自动重启，等待 1、3、10 秒，最多 3 次；连续运行满 60 秒后发生的新崩溃重新计算额度。启动失败（包括端口占用、配置错误）停止重试；主动停止、上游请求错误和健康检查超时不触发自动重启。
- 页面展示恢复中、重试次数和预计时间；失败后可手动重试或经原有确认流程恢复原生配置。不重放中断请求，不自动重启 Codex。
- 管理服务重新启动时，已有接入配置进入等待恢复，不自动启动网关；用户选择恢复接入或恢复原生配置。迁移中断仍通过现有 CLI 恢复，不增加备份恢复向导。
- 父进程退出使私有管道关闭，子进程退出；网关下一轮请求读取已提交的配置，保留配置热更新。
- 自动化覆盖网关崩溃重启、重试耗尽、主动停止、父进程退出、重启后的恢复入口、端口冲突及配置更新。双平台安装与打包实机验收仍未完成。
