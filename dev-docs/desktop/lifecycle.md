# 桌面生命周期

启动不会自动开启接入或恢复残留网关。首次使用需显式初始化。残留接入由用户选择恢复服务，或预览并确认关闭接入。配置切换与独立重启共用预览、版本和活动检查，配置结果与 Codex 操作结果分别反馈。

## 共有行为

托盘菜单包含管理、混合路由、重启 Codex 和退出。勾选仅表示配置已接入，网关健康以状态提示和管理页为准。原生层每五秒尝试刷新状态，控制会话忙时跳过，断连禁用切换。窗口关闭隐藏并保留草稿、控制会话与网关。退出期间暂停轮询，避免创建新会话。

托盘切换先预览再提交，取消不写配置。独立重启要求明确确认与两分钟单次票据，正常退出失败时停止后续启动。真实 Codex 操作复用各平台既有实现。

## macOS

使用 AppKit 原生确认。关闭窗口隐藏，Dock 重开显示窗口。Cmd+Q、自定义应用菜单和托盘退出进入安全检查。自管接入阻止退出时引导预览恢复原生配置，确认后另行检查停服安全，状态未知或依赖尚存时保留服务。

桌面可复用已确认归属的同目录网页服务。此时桌面退出仅断开连接，不停止外部服务。托盘路由操作通过共用 `web_api` 业务，独立重启仍复核路由与网关状态。

## Windows

使用 TaskDialog 原生确认，右键打开托盘菜单，双击恢复管理窗口，包括最小化窗口。操作弹窗保持管理窗口原有显示状态。路由已关闭且没有在途请求时可直接退出。接入开启、有在途请求或无法确认安全时可请求原生确认，确认后退出桌面及其拥有的网关，保留已保存路由配置。Windows 的安装识别、Restart Manager、Store 激活、单实例和系统代理规则分别维护。

## 异常与恢复

控制进程退出或 stdin EOF 清理其拥有的网关子进程，保留磁盘配置与恢复基线。此路径可能中断请求。下一次启动要求用户明确选择恢复。无响应、实例锁、共享服务断连与真实客户端操作需分别验证。

历史实现与平台验证边界保留在[页面对齐](../archive/desktop/web-desktop-alignment-history.md)、[私有协议](../archive/desktop/private-management-history.md)及[Windows 托盘增量](../archive/desktop/handoff-history.md#2026-11-05-windows-托盘对齐)。当前待验收项见[状态清单](status.md)。

## 接入事务与客户端操作

开启和关闭两个方向串行执行，处理中阻止重复提交。预览读取可信基线、配置与索引，展示活动与客户端检测。进程运行或检测未知时提示影响，由用户确认继续。开启与关闭分别保存 ask、auto、never 偏好，ask 默认不勾选 Codex 操作，自动偏好仍要求本次切换确认。

选择操作 Codex 时先尝试正常退出，退出失败仍可继续配置切换并反馈手动重启。成功退出后重新规划索引并复核配置。配置提交失败后停止后续启动，配置成功后最多尝试启动一次。开启允许启动原先未运行的应用，关闭保持原先未运行的应用停止。独立重启仅针对已运行且身份可确认的应用。安装未识别、状态未知或进程身份变化时反馈手动处理。重启影响整个应用与全部窗口，当前没有客户端加载确认或待重启状态。

开启先保证网关健康，再提交配置及索引事务。关闭只恢复本次接入前受管路由字段，保留原先字段不存在的状态、无关修改与根级 `model`。profile 或其他 provider 在预检阶段拦截。可信基线缺失、外部受管字段冲突或旧事务未恢复时阻止写入。重复开启保留首次基线。取消预览保持配置与索引原状态，已刷新本地目录的效果单独保留。

### 会话索引与恢复

事务处理默认 Codex 数据目录内的本机会话索引，包括归档与子会话。开启将索引路由改为 `codex-hybrid` 并保留模型。关闭改为 `openai`，官方模型保留，第三方模型替换为目录首个可用官方模型，原先未设置的模型保持未设置。再次开启不会恢复此前替换的第三方模型。缺少官方名单或必要回退模型时停止。

确认后仅在缺索引时调用独立 Codex app-server 的 `thread/read` 补齐元数据，使用临时认证存储并阻断 HTTP 联网。补齐产生的数据在后续迁移失败时保留。此能力用于索引，与任务状态探测分别维护。

特定结构不兼容、路径不安全、会话 ID 冲突或无索引元数据识别失败时，网页/桌面可警告后跳过全部索引迁移而继续配置事务，CLI 严格报错。官方模型校验、预览校验、索引补齐、备份和实际写入错误仍失败。

配置、恢复元数据与索引一同备份并事务提交，普通失败回滚，中断或回滚未完成保留 journal 并阻止后续操作。`session-migrations/<ID>/` 在成功、完整回滚或恢复完成后清理，失败时在启动及后续切换重试；首次基线位于 `session-baselines/`，独立保留。中断恢复需退出 Codex，使用现有 CLI。

历史文件转换有独立版本规则。关闭路由时的 `greeting-message-id-v1` 例外须遵守[已有 ADR](../decisions/001-history-compatibility.md)的目标、备份与哈希范围，不能把索引迁移扩展为通用历史重写。详细用户边界见[会话迁移](../../docs/zh-CN/session-migration.md)。

## 网关监督与活动

仅意外退出触发 1、3、10 秒退避，最多三次，稳定运行 60 秒重置额度。启动失败、主动停止、单次上游错误和健康检查超时分别反馈，管理服务重启后等待用户恢复选择。重试不重放已中断请求。

活动仅统计网关官方与第三方未结束请求/流，异常、取消与断连释放计数，管理页连接测试独立。活动为内存状态，零请求不能推导客户端任务结束。只读识别区分桌面、CLI 与 VS Code，权限不足显示未知。恢复配置成功后仍需另外判断停服依赖。
