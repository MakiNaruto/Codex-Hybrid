# 桌面开发预览

[English](../en/desktop.md) · [文档导航](README.md)

桌面版使用与网页端共用的管理页面，提供配置、模型、Codex 接入预览和托盘操作。当前为开发预览，正式安装包、签名及干净环境验收仍待完成。

## 获取与启动

macOS 当前顶层构建入口支持 Intel x86_64，生成 `desktop/build/stage0/Codex Hybrid Tray Preview.app`。Windows x64 生成 `desktop/dist/stage0/windows-x86_64/` 便携目录，保留 `Codex Hybrid.exe` 和 `hybrid-stage0-probe.exe` 在同一目录后启动窗口。Apple Silicon 尚待本机验收。

从源码构建的前置条件和命令见 [macOS 构建](../../dev-docs/desktop/build-macos.md)与 [Windows 构建](../../dev-docs/desktop/build-windows.md)。这些开发指南目前以中文维护。

## 首次初始化与来源设置

桌面固定使用用户的 `~/.codex-hybrid` 和 `~/.codex`，不采用 CLI 的目录环境变量覆盖。首次打开点击初始化，现阶段要求官方 Codex 已生成配置和模型缓存。初始化准备管理配置与恢复基线，启动应用和初始化均不会自动开启接入。

在管理页面配置厂商、模型与 Key，详情见[配置指南](configuration.md)。CC Switch 来源保持只读。保存时 Key 留空保留已有值，未保存草稿在操作失败后保留。连接测试需要主动点击，会访问供应商且可能计费。

## 预览、接入与恢复

选择预览开启或关闭接入，检查活动请求、模型和索引影响，再明确确认。可选的 Codex 操作需另外确认。切换配置成功与客户端已加载配置分别反馈。

上次异常退出后，如配置仍接入，页面会要求明确选择恢复接入服务，或预览并确认关闭接入。接入开启、网关状态与模型远端可用性需要分别查看。[使用与验证](usage.md)说明业务验证方法。

## 托盘与退出

两个平台均提供管理、混合路由、重启 Codex 和退出菜单。勾选表示配置已接入，详细网关状态见提示和管理页。关闭窗口会隐藏并保留草稿与服务，结束应用请使用退出入口。取消确认框不提交操作。

### macOS

关闭后可通过托盘管理或 Dock 重开窗口。Cmd+Q 与托盘退出进入安全检查。接入开启时可能先要求预览恢复原生配置，确认后再检查能否安全停服。复用已有网页服务时，退出桌面仅断开连接，原服务继续运行。

### Windows

右键通知区域图标打开菜单，双击恢复管理窗口。退出时如接入开启、有在途请求或安全状态未知，会显示原生确认。确认后退出桌面与其拥有的网关，保留已保存的路由配置，下次启动需按提示恢复。

真实 Codex 重启、完整托盘点选及部分原生交互仍待各平台实机验收，当前边界见[开发状态](../../dev-docs/desktop/status.md)。

## 更新与问题恢复

先正常退出旧预览，再重新构建并替换完整产物。Windows 两个 EXE 一起更新，macOS 更新完整 `.app`。开发预览尚无已验收的自动更新流程。用户数据位于上述固定用户目录。

启动失败、配置错误和回滚方法见[常见问题](troubleshooting.md)。异常断连会保留磁盘配置与恢复基线，重开后按照页面提示选择恢复。真实连接测试和 Codex 重启应在确认影响后执行。
