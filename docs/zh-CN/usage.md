### 网页端 Codex 接入开关（最小版本）

在现有本地管理页中使用“Codex 接入”开关。开启前展示变更说明，确认后保存路由和模型列表配置；取消不会修改配置。关闭时恢复本次接入前的相关字段（包含字段原先不存在的情况），保留其他配置修改。预览后配置变化、接入字段被外部修改或备份校验失败时停止切换，检查配置后刷新重试。

页面无法确认 Codex 已重新加载。当前切换还会处理本机会话的线路元数据，开启和关闭接入都建议先结束任务，但可在独立浏览器确认影响后继续，不因进程检测结果阻止切换。完成后手动重启 Codex；关闭后选择官方模型。详细范围与备份说明见[会话迁移](session-migration.md)。管理页和网关服务继续运行，关闭网页不会撤销接入。此版本要求先完成现有安装并启动本地服务，不包含桌面打包、托盘、进程启停、任务活动检测或自动重启。

接入区域每秒读取网关未结束请求数，切换确认中也会展示检测快照。计数覆盖经过此网关的官方和第三方请求及流，不包含网页连接测试。检测失败时显示状态未知；计数仅在内存保存。Codex 任务状态目前无法读取，始终显示未知：工具执行或等待审批时可能没有网络请求，因此“未检测到活动”不代表可以安全重启。确认后也可能出现新请求。

### 配置与日常操作

首次安装可在向导选择 `3 = 稍后在网页配置`，先进入空管理页。页面顶部按“配置模型 → Codex 接入 → 重启并验证”展示准备情况；“已找到凭据”仅表示本地能读取 Key，不代表厂商认证成功。不会自动发送连接测试。

支持按厂商、模型名称或 ID 搜索，并筛选启用状态。模型卡片可复制模型 key。高级参数中可设置厂商请求超时（1–3600 秒）；单次连接测试仍固定使用 60 秒连接超时。

表单修改后标记“未保存”。自动刷新和保存其他厂商会保留这些草稿；手动刷新、切换来源或离开网页前会提醒。草稿只存在当前页面内存，不写浏览器存储。保存会清空 Key 输入框并更新目录。

接入配置或已发布模型目录改变后，顶部持续提示手动重启。完成后可点击“我已手动重启 Codex”，刷新页面或重启服务也保留确认记录；这只是用户确认，不是进程或加载结果检测。仅修改 Key/API 地址不改变目录时无需再次确认。

### 运行与诊断

管理页自动读取一次运行状态，也可在底部点击“刷新状态”，查看服务运行时长和最近错误摘要。摘要从当前 `service.jsonl` 末尾最多 128 KiB 中提取最近 20 条错误，不是完整请求历史，也不搜索旧轮转文件。

点击“下载脱敏诊断”会重新读取状态并下载 JSON 文件。只包含服务状态、接入模式、活动计数、错误类别、阶段、时间、HTTP 状态码和耗时；不包含原始配置、完整日志、Key、认证头、聊天文本或工具参数，不自动上传。读取失败时显示错误；没有错误摘要也不代表完整日志中没有错误。

正式入口启动后，运行日志 `service.jsonl` 和错误日志 `service.stderr` 按 2 MiB 轮转，各保留 3 份旧文件。异常大的元数据记录会压缩为摘要。后台启动的早期错误写入 `service.startup.stderr`，该文件每次启动重新创建。旧版本尚在运行时需先重启服务才能使用新版日志策略。

### 测试模型连接

打开管理页，保存并启用模型，再点击“测试连接”。测试发送 `Reply with exactly hello and nothing else.`，
输出预算最多 8192 tokens；若模型配置上限更低，则使用更低值。
成功仅表示这次基础请求完成，完整 Codex 会话和工具调用仍需单独验证。

### 在主会话中使用第三方模型

在 Codex 原生模型列表中选择已配置的模型，新建会话并发送：

```text
只回复：Hello World
```

预期回复 `Hello World`。新会话便于确认模型选择；完整会话包含系统提示、工具说明与历史，
输入量通常比管理页连接测试大。

### 让官方主 agent 调用第三方子 agent

主会话选择支持原生子 agent 的官方模型，发送以下最小 prompt。**先替换模型 key**：手动示例是 `deepseek/flash`，向导填写模式是 `custom/default`，CC Switch 以实际注册目录为准，可用 `status` 查看模型 key 列表。

```text
请创建一个原生子 agent，model 使用 deepseek/flash，fork_turns 使用 none，
reasoning_effort 使用该模型支持的 low。
子任务：只回复 CHILD_OK，不调用工具。
请先声明将使用哪个模型创建子 agent，创建后等待完成，再转述结果。
不要用主 agent 自己作答来代替子任务，也不要通过 MCP 或命令行代调用。
```

预期：主 agent 声明模型 → 原生子 agent 活动出现 → 子 agent 回复 `CHILD_OK` → 主 agent 转述。客户端需具备并允许原生子 agent 工具；若当前环境没有该工具，提示词本身不能启用它。

以原生子 agent 活动中的模型信息和网关日志核实实际路由，不能仅凭模型自称使用了某供应商。

## 日常管理

服务启停与状态查询见 [常用命令](../../README.zh-CN.md#常用命令)。后续命令使用统一用户目录，自定义目录需持续显式指定；
目录优先级见 [命令行默认配置](cli.md#实例配置)，迁移说明见 [数据目录](configuration.md#数据目录)。
执行 `refresh-models` 后需重启服务并完全退出、重开 Codex。

新增或删除模型后，需要更新客户端模型列表并重启 Codex。仅更新 Key 或 API 地址时下一轮请求生效。
更多操作见 [配置指南](configuration.md) 和 [命令与安装进阶](cli.md)。

### 切换接入与会话迁移

开启或关闭接入时会同步迁移本机会话的 provider 和默认模型。请先完全退出 Codex，在独立浏览器中操作管理页；默认模型可指定，留空取目标列表首项。备份位置、命令行参数和中断恢复见[会话迁移说明](session-migration.md)。
